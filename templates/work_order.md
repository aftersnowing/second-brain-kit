# 작업 지시서 — 메일 요청을 claude_work 건으로 넘길 때 (양식)

> 격리 규율의 **예외**다 (`CLAUDE.md`, 2026-09-15 사용자 결정): 지시서에는 **요청 요지**까지 옮길 수 있다 —
> 요청자 · 요구 항목 · 기한 · 근거 포인터. **원문 인용과 본문 서술은 second_brain 에 남는다.**
> 건 쪽에서 더 필요하면 `ask.py thread <mailSN> --folder <folderSN>` 으로 직접 조회한다.
>
> 쓰는 법: 이 파일을 복사해 건의 `docs/` 또는 `README.md` 에 붙인다. 파일명 `YYYYMMDD_<요지>_작업지시.md`.

## 요청

- **요청자**: (이름 · 소속 — 예: ○○○ 팀장 / ○○팀)
- **근거**: `mail:<folderSN>/<mailSN>` (또는 `note:YYYY-MM-DD-NN` — 구두 지시·회의)
- **요구 항목**: (원문 문장이 아니라 **요지**. 예: 대상별 평균 초과율 · 사유별 원인 정리)
- **기한**: YYYY-MM-DD (근거: 미팅 일자 등)
- **용도**: (보고용 / 대외 회신 / 내부 대응 재료 — 산출 형태가 갈린다)

## 착수 결정 (사람이 정한 것)

| 결정 | 값 |
|---|---|
| 수치 트랙 | 이론 / 실측 / 병기 |
| 범위 | 대상 선박·기간·모드 |
| 제외·주석 | 데이터 약한 대상, 본문에서 뺄 항목 |
| 산출 형태 | 메일 본문 / 워크북 / 도면 / 보고서 |

## 자산 지도 (읽기 전용)

- **맥락**: `second_brain/wiki/cases/<사안>.md`
- **수치 원천**: `<건 경로>/…` (판본·기준일까지 적는다 — 예: `<판본 폴더>/<파일>.csv`, 기준일 YYYY-MM-DD)
- **원인 판정**: `<건 경로>/docs/knowledge/*.md`
- **판단 기준**: 관련 메일·메모 포인터 (예: 상사 지시 `mail:<f>/<s>`)

`ask.py work <folderSN>/<mailSN>` 이 붙일 건 후보를 제안한다 (의미 상위 3 + 개체로 이어진 건). **제안일 뿐이므로 사람이 고른다.**

## 산출과 반환

- 산출물은 **건 안에** 만든다 (`claude_work/CLAUDE.md` §2·§7 — 공용 자산은 읽기 전용).
- 메일로 나갈 것은 `second_brain/outputs/YYYYMMDD_<주제>_<형태>.md` 에 두고, 머리에
  **`요청: \`mail:…\``** 과 **`- **제목**: …`** 줄을 반드시 넣는다 → `wiki/loop.md` 가 이것으로 초안·발송·종결을 잇는다.
- 새 건을 만들 때는 `case-intake` 로 LEDGER 등재 후 착수한다. **등재 없이 디렉토리를 만들지 않는다.**

## 되돌아오는 것 (종결)

1. 산출물 → `save_draft.py` → **임시보관함**
2. 사람이 확인·발송
3. 다음 refresh 에서 보낸메일함 감지 → `wiki/loop.md` 「닫힘」
4. 재사용 가치가 있으면 사안 위키에 판정으로 환원 (`INGEST`), 도메인 일반화는 `harvest.md` 3문으로
